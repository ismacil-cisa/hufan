# HUFAN

**Digital Solutions & Creative Technology**

HUFAN is a digital solutions and creative technology agency focused on building modern, responsive, and user-friendly digital experiences for businesses and organizations.

## 🌐 Website

The HUFAN website is a static, responsive website designed to showcase the agency's:

- Digital services
- Projects and case studies
- Development process
- Company information
- Insights
- Contact information

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Light and dark mode
- English / Somali language switching
- Saved theme and language preferences
- Accessible navigation and UI
- SEO-friendly HTML structure
- Open Graph and social sharing metadata
- Structured data where appropriate
- Responsive mobile navigation
- Contact form interface prepared for backend/email integration
- Static-hosting compatible architecture

## 🛠️ Technologies

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Node.js
- Tailwind CSS CLI

## 🚀 Local Development

Clone the repository:

```bash
git clone <repository-url>
cd hufan
```

Install dependencies:

```bash
npm install
```

Run Tailwind in development mode:

```bash
npm run dev
```

Build the production CSS:

```bash
npm run build
```
